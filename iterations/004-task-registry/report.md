# Итерация 004 — контекстная база и ветка isaac

Дата: 9 ноября 2026. Основание: прямые инструкции пользователя вести единый реестр,
подробные отчёты/ревью и коммитить текущую задачу в отдельную ветку isaac.

Созданы TASK_REGISTRY.md и AGENTS.md. Реестр фиксирует цель переноса, ограничения,
окружение, доказанные результаты, непроверенные части и план следующего шага.
Материалы выполненных шагов перенесены в iterations/000–003; старые пути оставлены
как ссылки для совместимости. Для каждого шага добавлено явно обозначенное
ретроспективное ревью. Старый план отмечен историческим.

Ветка isaac создана от существующего состояния f52246c, содержащего runtime,
сборку навигации и успешный импорт/рендер. Вспомогательная синхронизация и инструкции
обновлены на isaac. Ветка isaac-migration сохраняется как история.

Проверки: относительные ссылки документации, git diff --check, совпадение состояния
рабочих копий и опубликованной ветки. Подтверждение публикации — GitHub ref isaac
и Git HEAD обеих копий после завершения этого шага. Исполнение симуляции не менялось;
повторный запуск GPU и набора тестов для документационного шага не требуется.

Следующая реализация: итерация 005, управление базой и истинная одометрия.
