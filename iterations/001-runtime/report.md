## Исправления стартового теста

Официальный образ по умолчанию использует uid=1234, который не может писать
в папку пользователя uid=1005. Для первоначального теста явно выбран root
внутри контейнера с OMNI_KIT_ALLOW_ROOT=1; собственные runtime-кэши изолированы.
Для дальнейшей среды стоит настроить непривилегированного пользователя и совпадающий UID.
Путь результата привязан к файлу сценария, а не к текущей директории Kit.
Ошибка Python фиксируется до вызова app.close: один exit=0 не считается успехом.
При повторном старте симулятора /clock сбрасывается; внешний probe запускается
заново для каждого эпизода, а не переживает reset.
